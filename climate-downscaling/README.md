requirements.txt is the python packages needed to train the SRDRN model
Network.py is the python file for the SRDRN model

train.py is the python file for training the SRDRN model

Custom_loss.py is the loss function used for training the SRDRN model

postprocess.py is the python file for post processing the outputs of the SRDRN model

submit.sh is a bash file for submitting a job for training SRDRN model at a hpc center, which will be different from center to center

QDM is R code to use QDM to bias correct each variable of the outputs from SRDRN model
